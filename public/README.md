# Public Assets

Place your `logo.png` file in this directory.

The logo.png file will be used for:
- Website header logo
- Favicon (browser tab icon)
- Open Graph image (social media previews)
- Search engine icons

**Recommended logo specifications:**
- Format: PNG (with transparency support)
- Size: 512x512px or larger (square format works best)
- The system will automatically resize it for different uses

Once you add `logo.png` to this folder, it will be automatically used throughout the application.
